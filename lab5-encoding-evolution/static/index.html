ทิปจำเร็วจากบทที่ 4 (หน้า 8):
JSON (81B) > MsgPack (66B) > Thrift (59/34B) > Protobuf (33B) > Avro (32B)

🔬 การทดลองที่ 1: ผ่าดูขนาดไบต์จริง (ตอนที่ 3 – ตอนที่ 7: ทำไม JSON ถึง 81 ไบต์ แต่ Avro เหลือแค่ 32 ไบต์?)

ลองแก้ชื่อผู้ใช้หรือตัวเลขด้านขวา แล้วกดคำนวณเพื่อดูการเปลี่ยนแปลงของชุดไบต์ในแต่ละรูปแบบได้ทันที

🔍 ผ่าไบต์ Protocol Buffers (33 ไบต์) — ใช้หมายเลขประจำช่อง (Field Tag #1, #2, #3)
